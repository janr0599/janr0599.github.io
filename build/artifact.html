Branch 1 · Law firmLive · 2024n8n

Client onboarding, 40 minutes to 40 seconds

Problem
Every new client meant 25 to 40 minutes of retyping the same details into the CRM, billing, time tracking and a welcome packet, by hand, by whoever was free.
Build
One Airtable trigger. Dedupe against existing clients, create the client, project and billing records, set up the Clockify project, pick the right document template by case type, generate it, upload to SharePoint, send the welcome email. 60 nodes, 33 with retry or error handling.
Result
About 40 seconds per client, unattended, since mid-2024.

Branch 4 · Vendor evaluationDelivered · 2026n8nPythonClaude

Measuring a legal-AI parser instead of trusting it

Problem
A client needed to know whether a document-parsing API was worth adopting. The vendor's numbers were the vendor's.
Build
An n8n workflow that runs one document down two paths, plain text and the vendor's structured output, through the same model with the same prompt, and a Python probe that checks every claim against the source PDF. Six documents, two runs each.
Result
51 to 93% fewer input tokens, 24 of 24 citations correct, one reproducible defect the vendor confirmed. The numbers are now in the vendor's public benchmark post.
